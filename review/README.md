# Επανάληψη των εννοιών

Το αρχείο `questions.md` περιλαμβάνει σύντομα ερωτήματα ελέγχου για κάθε στάδιο της έρευνας. Η απάντηση τεκμηριώνεται στις αντίστοιχες ενότητες του σημειωματαρίου και, όταν χρειάζεται, στο πλήρες κείμενο της πρότασης.
