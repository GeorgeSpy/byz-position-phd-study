# Πρωτότυπη βάση του αναγνωστηρίου

- `proposal-v871e-candidate.pdf`: το PDF με αποκατεστημένο το σχήμα, όπως δόθηκε από τον συγγραφέα.
- `proposal-v871e-candidate.tex`: το αντίστοιχο πηγαίο κείμενο εργασίας.
- `formula_position_example.png`: η εικόνα που χρειάζεται η εντολή includegraphics του πηγαίου.
- `reader-manifest.json`: χάρτης παραγόμενων ενοτήτων, σταθερών στόχων και βιβλιογραφικών εγγραφών.

Οι διαδρομές παραγωγής του LaTeX αναφέρονται στην εικόνα αυτού του φακέλου. [Προέλευση και έκδοση](../docs/reference.md).
