# Terminology

<!-- language-switch:start -->
**Language / Γλώσσα:** [Ελληνικά](../TERMINOLOGY_GR.md) · **English**
<!-- language-switch:end -->

| Term | Definition |
|---|---|
| Neume | A graphic sign in musical notation. |
| Atomic event | A unit of the common computational reference layer. Its relationship to neumes is recorded in digital encoding. |
| Melodic formula (*thesis*) | A historically grounded, organised melodic formation of variable length. Historical name, family, occurrence and realisation are distinguished in the [definitions](docs/current/position-and-family.md). |
| Named historical formula | A type named or described in a specified source or analysis. Its correspondence with analytical families is documented. |
| Realisation | The symbolic content of an occurrence in a declared representation and at a specified level of analysis. |
| Occurrence | The localised presence of a formula in a passage of a particular work and source. |
| Formula family | An analytical category with a versioned specification, diagnostic relations and a register of occurrences judged to be members. |
| Family specification (membership specification, family signature) | The diagnostic relations, scope, sufficient alternative configurations and exclusion criteria used to assess family membership. Greek prose consistently uses “προδιαγραφή οικογένειας”. |
| Exegesis | A later, more analytical rendering of an older chant passage. |
| Metrophony | The reading of quantitative neumatic signs as a succession of intervallic movements. |
| Performance | A chanter’s vocal rendering of a written realisation, with its own timing and pitch shaping. |
| Supervision | The information from which a model learns. A positive pair indicates that two examples are connected by the relation under study. |
| Encoder | A model that converts symbolic input into a numerical representation whose distances are used for comparison. |
| Reference model (comparator, baseline model) | A model used as a point of comparison in evaluation. The role covers simple baselines and strong neural models. |
| Reference method | An algorithm or broader approach used for comparison. |
| Reference condition | An experimental configuration used for comparison, such as family-based supervision with matched context. |
| Finalised specification or protocol | A fixed version established before evaluation. Greek prose uses “οριστικοποιημένη προδιαγραφή” or “οριστικοποιημένο πρωτόκολλο”. |
| Frozen parameters | Model parameters or weights that remain fixed during the relevant stage. |
| Reference labels or data (ground truth) | Independently documented evaluation targets, with their provenance and verification procedure recorded. |
| Pilot study | An initial, small-scale feasibility study, termed “πιλοτική μελέτη” in Greek. |
