## Correspondence and updates

Each translated page has a link to its Greek counterpart, which links back to English. Existing Greek text and addresses are preserved. Primary-source images and PDFs retain their original paths.

The [translation register](../manifest.json) records the source Git blob for every page, using the Greek edition at commit [d34366b](https://github.com/GeorgeSpy/byz-position-phd-study/commit/d34366b163346c93223880f175f6f431dcafeeff). The small language-selector block is excluded from source-content comparison. Changes to the underlying Greek text are detected by the bilingual checker, so the English version can be updated alongside them.

## Checks

From a full repository checkout, run:

~~~sh
python scripts/check_bilingual.py
python scripts/check_reader.py
~~~

For the first bilingual release, add <code>--preserve-originals</code> to the bilingual command to compare every original file with the recorded baseline. Later intentional source revisions require corresponding updates to the translation register.

The bilingual check covers page correspondence, source hashes, preservation of all original files, display equations, internal links and English anchors. The existing reader check remains unchanged and covers the Greek analytical reader.

English terminology follows the selected English proposal: **melodic formula, formula family, occurrence, realisation and exegesis**. Mathematical notation is retained, with English words used for membership judgements.
