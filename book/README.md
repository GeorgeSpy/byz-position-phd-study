# Προηγούμενο εγχειρίδιο

Το PDF και το LaTeX αυτού του φακέλου αφορούν το σημειωματάριο **v8.71a** και διατηρούνται ως προηγούμενο βοήθημα.

Η ενημερωμένη είσοδος είναι η [σύνοψη της πρότασης](../docs/start/overview.md). Η αναλυτική ανάπτυξη βρίσκεται στον [πλήρη χάρτη](../docs/full/index.md), μαζί με την [πλήρη βιβλιογραφία](../docs/bibliography/index.md). Το [τρέχον PDF βάσης](../sources/proposal-v871e-candidate.pdf) διατηρεί την αρχική σελιδοποίηση.
