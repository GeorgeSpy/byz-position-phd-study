# Προηγούμενο σημειωματάριο

Το υλικό αυτού του φακέλου διατηρεί προηγούμενα σημειώματα μελέτης της πρότασης.

Η τρέχουσα ανάγνωση αρχίζει από το [Σχέδιο βασικού ερευνητικού πυρήνα](../documents/core-research-plan.pdf), την [Αναλυτική ερευνητική πρόταση](../documents/analytical-proposal.pdf) και τη [σύνοψη](../docs/start/overview.md). Τα [στοιχεία προέλευσης](../docs/reference.md) εξηγούν τη σχέση των σημειωμάτων με τα κύρια κείμενα.

Το [πηγαίο κείμενο του προηγούμενου σημειωματαρίου](Simeiomatario_Erevnitikis_Protasis_v8_71a.tex) παραμένει διαθέσιμο με περιγραφικές αναφορές. Το παλιό PDF διατηρείται στο ιστορικό του αποθετηρίου.
