Η [βιβλιογραφία](../bibliography/index.md) παρέχει σταθερή σελίδα ανά εγγραφή και αυτόματα εντοπισμένες σχετικές ενότητες. Στο GitHub μπορεί επίσης να χρησιμοποιηθεί η αναζήτηση μέσα στο αποθετήριο.
