# Διαδρομές ανάγνωσης

[Σύνοψη](overview.md) · [Μεθοδολογικός χάρτης](../current/index.md) · [Θεματικό ευρετήριο](../topics.md)

Οι διαδρομές αρχίζουν από το ίδιο ερευνητικό αντικείμενο και οδηγούν σε διαφορετικό βάθος: συνολική παρουσίαση, μουσικολογική θεμελίωση, μαθηματική ανάπτυξη και τεκμήρια αξιολόγησης. Η [Σύντομη ερευνητική πρόταση](../../documents/short-proposal.pdf) και η [Αναλυτική ερευνητική πρόταση](../../documents/analytical-proposal.pdf) παρέχουν τις δύο κύριες μορφές ανάγνωσης.
