# Τεχνική τεκμηρίωση συγκριτικής μελέτης

Ο φάκελος περιέχει τις μαθηματικές προδιαγραφές, το πρόγραμμα αξιολόγησης, την τεκμηρίωση πηγών και τις υλοποιήσεις αναφοράς για τη συγκριτική μελέτη βυζαντινών θέσεων και ζναμένιων popevki.

## Θεωρία και μεθοδολογία

- [Μαθηματική αρχιτεκτονική](02_SELECTED_ARCHITECTURE_MATHEMATICAL_SPEC_GR.md): A0, ECSI-D[κ], πιθανοτικές βαθμολογίες, κανονικοποίηση και αλγόριθμοι.
- [Πρωτόκολλο αξιολόγησης](03_MINIMAL_DECISIVE_EXPERIMENT_AND_PROTOCOL_GR.md): E-min, P1/P2, συγκριτές και κριτήρια επιτυχίας.
- [Βιβλιογραφική τοποθέτηση](04_NOVELTY_AND_PRIOR_ART_DIFFERENCE_MATRIX_GR.md): γνωστές μέθοδοι και συγκριτικές ερευνητικές υποθέσεις.
- [Πηγές και ανεξάρτητη επισημείωση](05_DATA_PROVENANCE_IDENTIFIABILITY_AND_QREAL_GR.md): προέλευση δεδομένων, μουσικολογικοί ρόλοι, Q_real.
- [Ερευνητικό πρόγραμμα](06_ROADMAP_PUBLICATION_AND_PROPOSAL_INSERT_GR.md).
- [Υλοποίηση και έλεγχοι](07_IMPLEMENTATION_BLUEPRINT_AND_TESTS_GR.md).
- [Μητρώο τεκμηρίωσης και εκκρεμοτήτων](SOURCE_ACCESS_AND_UNRESOLVED_EVIDENCE.md).

## Υλοποιήσεις ελέγχου

Οι μικρές δοκιμές εξετάζουν ορισμένες μαθηματικές ιδιότητες σε **συνθετικά δεδομένα**. Δεν αποτελούν αξιολόγηση απόδοσης σε πραγματικό μουσικό corpus.

```bash
python -m pip install numpy scipy
python run_all_checks.py
```

Ο βασικός έλεγχος γεννητικής κανονικοποίησης βρίσκεται στο `profile_semantics_oracle.py`, οι διορθωμένες αναδρομές του συζευγμένου μοντέλου στο `ecsi_kappa_context_oracle.py` και η αμφίδρομη εκπαίδευση στο `bidirectional_learning_oracle.py`. Οι έλεγχοι παλινδρόμησης είναι συγκεντρωμένοι στον υποφάκελο `original_oracles/` και περιλαμβάνουν ιστορικά αντιπαραδείγματα. Το `validation_summary.json` καταγράφει εκδόσεις βιβλιοθηκών και καταστάσεις εξόδου.

## Όρια ερμηνείας

Τα συμπεράσματα περί μουσικής ταυτότητας, ιστορικής σημειογραφίας και μεταφοράς μεταξύ παραδόσεων παραμένουν **υποθέσεις προς εμπειρική επαλήθευση**, έως ότου υπάρξουν ανεξάρτητες επισημειώσεις, πηγολογικά τεκμηριωμένα χωρία και προκαθορισμένη συγκριτική αξιολόγηση.
