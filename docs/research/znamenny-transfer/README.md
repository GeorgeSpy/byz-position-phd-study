# Μελωδική ταυτότητα και παραλλαγή: βυζαντινές θέσεις και ζναμένιες popevki

Η συγκριτική αυτή ερευνητική επέκταση εξετάζει πώς διατηρείται η ταυτότητα μιας μελωδικής μονάδας μέσα σε διαφορετικές πραγματώσεις. Αφετηρία είναι η βυζαντινή *θέσις* και η αναλυτικά οριζόμενη οικογένειά της· συγκριτικό πεδίο είναι οι ζναμένιες *popevki*, με ανεξάρτητες οικογενειακές κρίσεις και τεκμηριωμένα τοπικά γνωρίσματα. Η σύγκριση αφορά τον τρόπο υπολογιστικής μελέτης της παραλλαγής και δεν προϋποθέτει ότι οι δύο παραδόσεις χρησιμοποιούν τις ίδιες μελωδικές μονάδες ή ότι υπάρχει άμεση ιστορική αντιστοιχία.

Στον ερευνητικό σχεδιασμό συνδυάζονται δομημένη αναγνώριση τμημάτων (A0), πιθανοτική στοίχιση μέσω του πυρήνα παραλλαγής $\kappa$ και μουσικολογικές προδιαγραφές ECSI-D[$\kappa$]. Τα πειράματα P1 και P2 εξετάζουν χωριστά τις δύο κατευθύνσεις της σχέσης μεταξύ στοίχισης και μουσικολογικής γνώσης. Το E-min εξετάζει ανεξάρτητα κατά πόσο η οργάνωση της παραλλαγής μπορεί να μεταφερθεί μεταξύ των παραδόσεων.
