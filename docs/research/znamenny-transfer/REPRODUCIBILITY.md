# Αναπαραγωγιμότητα, έλεγχοι και όρια των αποτελεσμάτων

Η τεχνική υποδομή περιλαμβάνει ανεξάρτητους ελέγχους αλγοριθμικής ορθότητας, επαναληπτικές συνθετικές δοκιμές και μηχανικά αναγνώσιμες ρυθμίσεις πειραμάτων. Τα πρωτογενή αριθμητικά αρχεία διατηρούνται στον φάκελο `support/` ώστε οι ισχυρισμοί αλγοριθμικής ορθότητας να παραμένουν επαληθεύσιμοι.

**Συνθετικά επαληθευμένο:** 221 έλεγχοι εξωτερικού / γεννητικού μοντέλου, 308 ελέγχοι του διορθωμένου context-aware product DP και 43 έλεγχοι αμφίδρομης εκτίμησης, 572 συνολικά. Επιπλέον επανεκτελέστηκαν τα αρχικά oracles και το αντιπαράδειγμα ιστορικού εκπομπών. Αυτά **δεν** αποδεικνύουν εμπειρική επίδοση MIR ή συμφωνία ειδικών.

**Δεν έχει εκτελεστεί:** εκπαίδευση B1/B2 checkpoints σε πραγματικό ελεγμένο corpus Znamenny, independent-label P1/P2, E-min με πραγματικές μουσικές εμφανίσεις, επικύρωση ιστορικής ανάκτησης.

Εκτέλεση, από τον παρόντα φάκελο:

```bash
python -m pip install numpy scipy
cd support
python run_all_checks.py
```

Ο runner δημιουργεί τοπικά `.txt` logs, ανανεώνει τα JSON statuses και αναμένει μία ελεγχόμενη αποτυχία του **παλαιού** normalizer ως regression test. Η επιτυχία σημαίνει ότι αυτό το αντιπαράδειγμα *αναπαράγεται*, όχι ότι το παλαιό μοντέλο είναι ορθό. Τα checks χρησιμοποιούν συνθετικά δεδομένα και αναδρομές σε μικρά μεγέθη.

**Ανοιχτές εξαρτήσεις:** πραγματική πρόσβαση/άδειες σώματος, ανεξάρτητες μουσικολογικές κάρτες και σημάνσεις, πραγματικά όρια, αντιστοιχίσεις και πηγολογικός γράφος, budget εκπαίδευσης, calibration και προεγγραφή πριν από το εξωτερικό test. Βλ. `support/SOURCE_ACCESS_AND_UNRESOLVED_EVIDENCE.md`.

**Έλεγχος κανονικοποιητών:** `A_f` είναι κοινή μάζα εμφάνισης και μήκους, `a_f(n)` μάζα μήκους, `B_f` κοινή μάζα εμφάνισης και ικανοποίησης, `z_f(n)` μάζα μήκους και ικανοποίησης, `m_f=B_f/A_f`, `Z_f=z_f/a_f`. Το `r_f` είναι reference mass, όχι αυτομάτως ισοδύναμο με `Z_f`.

****Καθεστώς τεκμηρίωσης:** οι δοκιμές αφορούν μικρούς, ελεγχόμενους συνθετικούς χώρους και όχι αποτελέσματα αναγνώρισης σε πραγματικά μουσικά δεδομένα.
