## Στόχος

Ο μηχανισμός [a2s3_ingest.py](a2s3_ingest.py) αντιστοιχίζει μουσικολογικά ελεγμένες εμφανίσεις με τις σταθεροποιημένες βαθμολογίες των μοντέλων της A2. Εισάγει τις συνθήκες **FV, FP, DV, DP**, εκπαιδεύει το **B_L** στις κατάλληλες ομάδες ανάπτυξης και υπολογίζει τις **συζευγμένες αντιθέσεις πλήρους έκτασης έναντι περικοπής και επέκτασης**. Ο αριθμητής χρησιμοποιεί αποκλειστικά τις αποδεκτές εκτάσεις με την προτιμώμενη αρχή· όλες οι αποδεκτές οριοθετήσεις διατηρούνται για τον έλεγχο του χώρου υποψηφίων.

Η υποδομή προετοιμάζει την εισαγωγή πραγματικών δεδομένων. Οι τρέχουσες εκτελέσεις χρησιμοποιούν **συνθετικά παραδείγματα**· η εφαρμογή στο πραγματικό υλικό απαιτεί επαληθευμένες πηγές, επισημειώσεις και αποθηκευμένες βαθμολογίες από εκπαιδευμένα μοντέλα της A2.

## Τρία αρχεία εισόδου

| Αρχείο | Περιεχόμενο |
|---|---|
| `manifest.json` | Ταυτότητα συνόλου, κατάσταση δικαιωμάτων, κατάλογος οικογενειών, ακριβής σύμβαση δεικτών, ομάδες διαχωρισμών, συσχετισμένες ομάδες, αναγνωριστικά μοντέλων ανά επανάληψη/συνθήκη, αθροίσματα ελέγχου SHA-256 των δύο εξαγωγών |
| `annotations.json` | `occurrence_id`, έργο, μάρτυρας, ομάδα, οικογένεια, κοινό παράθυρο, όλα τα αποδεκτά ζεύγη ορίων, προτιμώμενη αρχή, περικοπή/επέκταση, κρίσεις των προβλεπόμενων ειδικών, άρθρωση, συνδετικό υλικό, λόγοι αποκλεισμού |
| `scores.json` | Σταθερές βαθμολογίες βάσης ανά επανάληψη, βαθμολογίες όλων των νόμιμων υποψήφιων τμημάτων για κάθε συνθήκη FV/DV/FP/DP και κάθε διαταραχή, κοινές βαθμολογίες παραλείψεων, αναγνωριστικά των αντίστοιχων εκπαιδευμένων μοντέλων |

Τα επισημειωμένα όρια και τα υποψήφια σημεία επέκτασης χρησιμοποιούν **απόλυτους δείκτες ατομικών γεγονότων, με αρίθμηση από το 0 και συμπεριλαμβανόμενο τέλος**. Η εξαγωγή βαθμολογιών χρησιμοποιεί **τοπικούς δείκτες 0…n−1 μέσα στο κοινό παράθυρο**. Κάθε υποψήφια έκταση βαθμολογείται για **όλες τις οικογένειες** του δηλωμένου καταλόγου.

Οι βαθμολογίες βάσης παρέχονται ως **ήδη θερμοκρασιακά βαθμονομημένα, μη κανονικοποιημένα λογαριθμικά δυναμικά** (`b_r/T_r`). Οι βαθμολογίες των συνθηκών FV/FP/DV/DP παρέχονται επίσης ως μη κανονικοποιημένα δυναμικά τμημάτων (*span potentials*). Η κανονικοποίηση πραγματοποιείται στον κοινό χώρο πλήρων νόμιμων αναλύσεων.

## Έλεγχοι ακεραιότητας

1. Ταυτόσημος χώρος υποψηφίων σε όλες τις συνθήκες και επαναλήψεις, με κάλυψη όλων των αποδεκτών οριοθετήσεων και των δύο παραλλαγών.
2. Διακριτές ομάδες `base_train`, `head_train`, `development`, `holdout`. Έλεγχος έργου, μάρτυρα και ιστορικά συνδεδεμένων ομάδων, ώστε η ίδια εξαρτημένη πληροφορία να ακολουθεί ενιαίο διαχωρισμό.
3. Μία κοινή σταθεροποιημένη βάση ανά επανάληψη. Τα μεταδεδομένα των κεφαλών της A2 ελέγχονται ως προς τη βάση, τις ομάδες εκπαίδευσης και τις ομάδες ρύθμισης.
4. Πλήρης κάλυψη των προδηλωμένων ειδικών, επιλεξιμότητα εναλλακτικών οριοθετήσεων, κατάλληλο συνδετικό υλικό και επιλογή δεξιού άκρου σύμφωνα με την κλίμακα άρθρωσης.
5. Αναμενόμενη διάταξη **5 επαναλήψεων × (2 έγκυρες + 2×10 διαταραγμένες συνθήκες)** ανά εμφάνιση. Η μικρή διάταξη **1×(2+2)** εξυπηρετεί αποκλειστικά τη δοκιμή της διεπαφής.
6. Επαλήθευση SHA-256 των ακριβών εξαγωγών και απόρριψη ελλιπών, μη πεπερασμένων ή ασύμβατων βαθμολογιών.

## Εκτέλεση

Από τον φάκελο `support/`, με Python 3.10 ή νεότερη:

```bash
python -m unittest -v test_a2s3_ingest.py
python make_demo_export.py /tmp/a2s3_demo
python a2s3_ingest.py /tmp/a2s3_demo/manifest.json /tmp/a2s3_demo/annotations.json /tmp/a2s3_demo/scores.json
# Πλήρης συνθετική δομή πέντε επαναλήψεων και δέκα διαταραχών:
python make_demo_export.py /tmp/a2s3_full --full
python a2s3_ingest.py /tmp/a2s3_full/manifest.json /tmp/a2s3_full/annotations.json /tmp/a2s3_full/scores.json
