# Α2–Helsen — Εκτελέσιμος πυρήνας μουσικολογικών προδιαγραφών

[Πειραματική μελέτη Α2–Helsen](../README.md) · [Μητρώο πειραμάτων Α–F1](../experiments/README.md) · [Τεχνικό πρωτόκολλο Α2](../../../../appendices/k.md) · [Συνθετικοί στατιστικοί έλεγχοι Α2](../../../a2/support/README.md) · [English](../../../../../en/docs/research/byzcorpus/a2-helsen/repro/README.md)

Ο φάκελος περιέχει τον αριθμητικό πυρήνα που χρησιμοποιείται για την αναπαράσταση μουσικολογικών προδιαγραφών, τον έλεγχο ελεγχόμενων διαταραχών και τον υπολογισμό των κύριων μετρικών της Α2. Η υλοποίηση δέχεται συμβολικές παρατηρήσεις και εξωτερικά ορισμένες οικογένειες. Το συνοδευτικό παράδειγμα και οι δοκιμές χρησιμοποιούν αποκλειστικά συνθετικά δεδομένα.

## Εγκατάσταση και εκτέλεση

Απαιτείται Python 3.10 ή νεότερη. Από τον παρόντα φάκελο:

```bash
python -m venv .venv
# Ενεργοποιήστε το περιβάλλον σύμφωνα με το λειτουργικό σύστημα.
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python -m examples.synthetic_example
```

Οι αριθμητικές εξαρτήσεις είναι **NumPy** και **SciPy**. Το scikit-learn χρησιμοποιείται προαιρετικά σε έναν πρόσθετο έλεγχο σύγκρισης της Average Precision· όταν απουσιάζει, ο συγκεκριμένος έλεγχος παραλείπεται και οι υπόλοιπες δοκιμές εκτελούνται κανονικά.

Η βασική τοπική επαλήθευση ολοκληρώθηκε με **14 επιτυχείς δοκιμές**. Το συνθετικό παράδειγμα εξετάζει δύο οικογένειες σε 16 δυαδικές καταστάσεις εννοιών και αναπαράγει πιστοποιημένα \(d_F=d_D=0{,}4\).

## Αναπαράσταση γνώσης

Κάθε οικογένεια περιγράφεται ως λεξικό με τρεις ρόλους:

- **R**: απαιτούμενες διαγνωστικές σχέσεις που συνδέονται με λογικό AND.
- **A**: εναλλακτικές ομάδες, με OR στο εσωτερικό κάθε ομάδας και AND μεταξύ ομάδων.
- **E**: αποκλειόμενες σχέσεις, οι οποίες αρνούνται πριν από τη συνολική λογική σύζευξη.

Η είσοδος αποτελείται από πίνακα δυαδικών γνωρισμάτων `values` και μάσκα παρατηρησιμότητας `observed`, με κοινό σχήμα `(N, C)`. Όταν `observed[i,j]=0`, η αντίστοιχη έννοια παραμένει άγνωστη. Ο τελεστής επιστρέφει `Q_R,Q_A,Q_E`, λογική κατάσταση `1,0,-1` και ποινή ίση με 1 μόνο για **διαπιστωμένη παραβίαση**.

Η προσθετική κεφαλή είναι \(\ell_F=b+Qw\). Η δομημένη κεφαλή είναι \(\ell_D=b+Qw-\lambda v\), με \(\sum_j w_j=1\), \(0{,}1\leq w_j\leq0{,}8\) και \(0\leq\lambda\leq2\).

Ο αριθμητικός πυρήνας υπολογίζει τροποποιήσεις στις βαθμολογίες των στοχευμένων οικογενειών. Η αντιστοίχιση στο πλήρες λεξιλόγιο κλάσεων, η εκμάθηση των νευρωνικών βαρών, η βαθμονόμηση θερμοκρασίας και η αποκωδικοποίηση ολόκληρων έργων ανήκουν στην ευρύτερη πειραματική υποδομή.

## Ελεγχόμενες διαταραχές

Η `propose_perturbations` κατασκευάζει κοινή, ένα-προς-ένα αντιστοίχιση εννοιών με σεβασμό στην κατηγορία γνωρίσματος, στη συχνότητα εμφάνισης και στο ποσοστό μη παρατηρησιμότητας. Οι περιορισμοί αξιολογούνται σε **μη επισημειωμένες καταστάσεις εννοιών από το εσωτερικό σύνολο ανάπτυξης**.

Κάθε αποδεκτή τροποποίηση πρέπει να αλλάζει την κανονική κάρτα κάθε οικογένειας, να διαθέτει παρατηρημένους μάρτυρες ικανοποίησης και παραβίασης, να είναι λειτουργικά διακριτή και να περνά τα γραμμικά προγράμματα \(d_F,d_D\). Η συνάρτηση καταγράφει τις απορρίψεις και τερματίζει όταν βρεθεί ο ζητούμενος αριθμός ή εξαντληθούν οι προτάσεις. Η μουσικολογική εξέταση των μεταθέσεων αποτελεί χωριστό βήμα της ερευνητικής διαδικασίας.

Τα πιστοποιητικά LP χρησιμοποιούν HiGHS, ελέγχουν την εφικτότητα, τη δυϊκή στασιμότητα και το κενό δυϊκότητας, και αναφέρουν συντηρητικό κάτω φράγμα. Η πιστοποίηση αφορά το δηλωμένο σύνολο καταστάσεων και το συγκεκριμένο πεδίο παραμέτρων.

## Μετρικές και στατιστική ανάλυση

Η `ap_with_ties` εισάγει ταυτόχρονα όλες τις ισοβαθμίες, σύμφωνα με τον μη παρεμβαλλόμενο ορισμό της AP. Η `macro_ap` υπολογίζει χωριστή ταξινόμηση «μία οικογένεια έναντι των άλλων». Η `pooled_seed_ap` συγκεντρώνει τις προβλέψεις των πτυχών **ανά seed** και στη συνέχεια υπολογίζει τον μέσο των πέντε αποτελεσμάτων, όταν παρέχονται πέντε επαναλήψεις.

Η `factorial_contrasts` επιστρέφει την επίδραση εγκυρότητας γνώσης, τη διαφορά δομημένης–προσθετικής χρήσης, τη μέση δομική επίδραση και την αλληλεπίδραση. Η `jackknife_t` επαναϋπολογίζει ολόκληρο τον εκτιμητή αφήνοντας εκτός μία ανεξάρτητη ομάδα κάθε φορά. Οι μη ορισμένες επαναλήψεις αναφέρονται ως σφάλμα που απαιτεί αξιολόγηση της κάλυψης.

## Σχέση με την πλήρη πειραματική σειρά

Η εκτελεσμένη Α2–Helsen χρησιμοποιεί τα πρωτογενή δεδομένα Helsen/CantusCorpus, εκπαιδευμένες νευρωνικές βάσεις και αποθηκευμένες προβλέψεις ανά πτυχή και seed. Τα αρχεία αυτά διατηρούνται στο ιδιωτικό ερευνητικό σύνολο, σύμφωνα με την [τεκμηρίωση προέλευσης και δικαιωμάτων](../experiments/provenance-and-rights.md).

Ο παρών κώδικας παρέχει **ανεξάρτητα εκτελέσιμη αναφορά των αριθμητικών τελεστών και των βασικών ελέγχων**. Για επανεκτέλεση των εμπειρικών αποτελεσμάτων απαιτούνται επίσης τα νόμιμα πρωτογενή υλικά, ο κώδικας εκπαίδευσης και οι πειραματικές ρυθμίσεις. Οι στατιστικές προσομοιώσεις του σχεδιασμού συνεχίζουν να τεκμηριώνονται στον υπάρχοντα φάκελο [A2 support](../../../a2/support/README.md).
