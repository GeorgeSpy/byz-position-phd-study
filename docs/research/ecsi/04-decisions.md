# Καταγεγραμμένες αποφάσεις και ανοιχτές πύλες

[Επιστροφή](README.md)

| Θέμα | Σημερινή θέση | Τι μπορεί να την ανατρέψει |
|---|---|---|
| Βασική έρευνα Μ1–Μ5, Α2 Μ2, Μθέσις, ATL/ATL-INV | **Διατηρούνται χωρίς σιωπηρή αναθεώρηση** | Ρητή μελλοντική αναθεώρηση του εγκεκριμένου πρωτοκόλλου |
| Οικογενειακή προδιαγραφή | Απαιτήσεις/υποστηρικτικές σχέσεις, περιβάλλον, αποκλεισμοί, επαρκείς κλάδοι | Πρωτογενής μουσικολογική αυτοψία/ανεξάρτητες κρίσεις |
| ECSI-D με εξαρτημένα διαγνωστικά | **Αρχιτεκτονική προεπιλογή προς pilot** | Ανεπαρκείς ή ανεξάρτητες τελικά άγκυρες, μη εφικτό inference, empirical results |
| ECSI-F (factored) | Υποχρεωτική ablation | Αν η εξαρτημένη εκδοχή δεν προσφέρει αξιόπιστο πλεονέκτημα σε προκαθορισμένα κριτήρια, επανεξετάζεται η απλούστερη λύση (χωρίς ισχυρισμό ισοδυναμίας από μη σημαντική διαφορά) |
| Συνεχές R1 | Υπό συνθήκη μ2/μ6 | Μόνο τεκμηριωμένες μονάδες και ανοχές πυρήνα |
| Συγκρίσιμες βαθμολογίες οικογενειών | Προτεινόμενος common-reference / calibrated scorer | Πρόβλημα κοινού semantics, r_F ή αποτυχία calibration |
| Πρόβλεψη χωρίς αληθινή οικογενειακή ετικέτα | Υποχρεωτικός έλεγχος leakage | Ανασχεδιασμός αν ο candidate-alignment μηχανισμός χρειάζεται oracle πληροφορία |
| Αποτελέσματα synthetic tests | Υποστηρίζουν correctness μόνο | Δεν αποδεικνύουν αληθινή απόδοση MIR |
| Πραγματικό pilot και paper | **Δεν έχουν ολοκληρωθεί** | Τεκμηριωμένες Π0′/Π1′/Π2′ και στατιστική επάρκεια |

Οι καταστάσεις στις συγκεκριμένες εγγραφές είναι ερευνητικές προεπιλογές, όχι πρόβλεψη επιτυχίας. Οι αποφάσεις αναθεωρούνται με προκαθορισμένα, ανεξάρτητα τεκμήρια.
