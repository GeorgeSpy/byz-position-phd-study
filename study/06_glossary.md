## Πίνακας των 40 Βασικών Όρων

| # | Όρος | Σύντομος ορισμός |
|---|---|---|
| 1 | **Μουσική θέση** | Αναγνωρίσιμος μελικός σχηματισμός μεταβλητής έκτασης. |
| 2 | **Οικογένεια** | Μουσικολογικά τεκμηριωμένη αναλυτική κατηγορία συγγενών πραγματώσεων. |
| 3 | **Εμφάνιση** | Συγκεκριμένο χωρίο συγκεκριμένης πηγής/έργου. |
| 4 | **Πραγμάτωση** | Η συγκεκριμένη μορφή εμφάνισης μιας οικογένειας. |
| 5 | **Εξήγηση** | Ιστορικά τεκμηριωμένη σχέση αποδόσεων, όχι απλή ομοιότητα. |
| 6 | **Provenance** | Διαδρομή τεκμηρίωσης από αρχείο/πηγή έως επισημείωση και συμπέρασμα. |
| 7 | **C_StA** | Καταλογογραφικό στρώμα Αγίου Αντωνίου. |
| 8 | **C_occ** | Μητρώο τεκμηριωμένων μουσικών εμφανίσεων. |
| 9 | **C_exp** | Ανεξάρτητο στρώμα επισημειώσεων ειδικών. |
| 10 | **Candidate signature** | Υποψήφια διαγνωστικά χαρακτηριστικά οικογένειας. |
| 11 | **Negative criterion** | Μουσικολογικό γνώρισμα αποκλεισμού από οικογένεια. |
| 12 | **Unresolved** | Τεκμηριωμένα ανεπίλυτη/αβέβαιη περίπτωση. |
| 13 | **Train / dev / test** | Εκπαίδευση / επιλογή αποφάσεων / ανεξάρτητη τελική αξιολόγηση. |
| 14 | **Leakage** | Μεταφορά πληροφορίας από αξιολόγηση ή συγγενή πηγή στην εκπαίδευση/επιλογή. |
| 15 | **u1** | Μονάδα νευματικού χαρακτήρα. |
| 16 | **u2** | Ατομικό μελωδικό γεγονός, όχι απαραίτητα ένα νεύμα. |
| 17 | **u3** | Προκαθορισμένη σύνθετη νευματική μονάδα. |
| 18 | **N / T / M / L** | Σημειογραφία / χρόνος / τροπική πληροφορία / κείμενο-προσωδία. |
| 19 | **R★** | Λειτουργικά επιλεγμένη αναπαράσταση από τη M1. |
| 20 | **M(R)** | Επίδοση ορίων αναπαράστασης R. |
| 21 | **G(R)** | Οικογενειακό κριτήριο της αναπαράστασης R. |
| 22 | **g_min** | Ελάχιστο προδηλωμένο κριτήριο οικογενειακής επάρκειας. |
| 23 | **𝓡★** | Σύνολο αβεβαιότητας γύρω από την επιλογή R★. |
| 24 | **Transformer encoder** | Μοντέλο που μετατρέπει συμβολική είσοδο σε τοπικές αριθμητικές καταστάσεις. |
| 25 | **h_t** | Τοπική κρυφή κατάσταση του γεγονότος t. |
| 26 | **Candidate span** | Υποψήφιο συνεχόμενο μουσικό τμήμα. |
| 27 | **Segment pooling** | Συμπύκνωση τοπικών καταστάσεων ενός τμήματος. |
| 28 | **z_id** | Αναπαράσταση οικογενειακής ταυτότητας τμήματος. |
| 29 | **Semi-Markov CRF** | Δομημένο μοντέλο που βαθμολογεί τμήματα μεταβλητού μήκους και οικογένειες. |
| 30 | **Partial likelihood** | Πιθανοφάνεια που επιτρέπει σύνολο συμβατών αναλύσεων. |
| 31 | **Open set** | Δυνατότητα αναγνώρισης ότι οικογένεια μπορεί να είναι εκτός λεξιλογίου. |
| 32 | **Abstention** | Αποχή από ανασφαλή ταξινόμηση. |
| 33 | **B0** | Άμεση συμβολική σύγκριση χωρίς representation learning. |
| 34 | **B1** | Κοινή μαθημένη αρχιτεκτονική χωρίς σχεσιακή εποπτεία B2/EISE. |
| 35 | **B2** | Θετικά ενδοοικογενειακά ζεύγη χωρίς τεκμηριωμένη εξηγητική ακμή. |
| 36 | **EISE** | Συνθήκη που χρησιμοποιεί ανεξάρτητα τεκμηριωμένες ιστορικές εξηγητικές σχέσεις. |
| 37 | **Δ_hist** | Διαφορά συμφωνίας EISE και B2 με ανεξάρτητο εκτελεστικό κριτήριο. |
| 38 | **A(z)** | Ιστορικό προφίλ παραλλαγής στη θέση z. |
| 39 | **Γ(z)** | Σύγχρονο εκτελεστικό προφίλ μεταβλητότητας στην αντίστοιχη περιοχή. |
| 40 | **PPM** | Πρόβλεψη από μεταβλητό μήκος προηγούμενου συμφραζομένου με backoff. |
| 41 | **I_F** | Πληροφοριακό περιεχόμενο επόμενης οικογένειας. |
| 42 | **I_event** | Πληροφοριακό περιεχόμενο μεμονωμένων μελωδικών γεγονότων. |
| 43 | **H_pred** | Αν το I_F εξηγεί ανθρώπινη έκπληξη πέρα από I_event. |
| 44 | **H_cat** | Αν η οικογενειακή ένταξη προβλέπει τριαδική επιλογή πέρα από επιφανειακή ομοιότητα. |
| 45 | **E_Byz** | Συνεχής δείκτης εξοικείωσης με τη βυζαντινή ψαλτική. |
| 46 | **R (M3c)** | Μη μουσική ένδειξη λατρευτικού συμφραζομένου. |
| 47 | **Ω** | Ρητά ορισμένο ιστορικό σώμα/μοντέλο/κανόνες αναφοράς για M5. |
| 48 | **D_fam** | Διαφοροποίηση κατανομής οικογενειών σε πλήρες έργο. |
| 49 | **D_within** | Διαφοροποίηση πραγμάτωσης μέσα στην ίδια οικογένεια. |
| 50 | **D_seq** | Διαφοροποίηση διαδοχών οικογενειών. |
| 51 | **D_func** | Διαφοροποίηση λειτουργικής τοποθέτησης οικογενειών. |
| 52 | **GREEN / AMBER / RED** | Επαρκής / αδρότερη / μη αξιόπιστα εκτιμήσιμη κλίμακα, βάσει προκαθορισμένων κριτηρίων. |
