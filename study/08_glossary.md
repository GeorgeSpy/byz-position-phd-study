# Γλωσσάρι βασικών όρων

| Έννοια | Σημασία |
|---|---|
| Μουσική θέση | Μελικός σχηματισμός με τροπική και φραστική λειτουργία. |
| Προδιαγραφή οικογένειας | Ρητός κανόνας ένταξης με διαγνωστικές σχέσεις, πεδίο εφαρμογής και κριτήρια αποκλεισμού. |
| Οικογένεια | Κατηγορία συγγενών πραγματώσεων με ελέγξιμα μουσικά γνωρίσματα. |
| Εμφάνιση | Συγκεκριμένο χωρίο έργου και πηγής. |
| Πραγμάτωση | Η συγκεκριμένη μορφή που παίρνει μία θέση. |
| Ιστορική εξήγηση | Τεκμηριωμένη σχέση μεταξύ παλαιότερης και αναλυτικής απόδοσης. |
| Προέλευση δεδομένων | Η διαδρομή από τη μουσική πηγή έως την επισημείωση και το συμπέρασμα. |
| Συμβολική αναπαράσταση | Αριθμητικά ή διακριτά σύμβολα για τη γραπτή μουσική πληροφορία. |
| Ατομικό γεγονός | Ελάχιστη αναλυτική μονάδα μελωδικής κίνησης του εξεταζόμενου σχήματος. |
| Οριοθέτηση | Εντοπισμός της αρχής και του τέλους μιας εμφάνισης θέσης στη M1. |
| Κατάτμηση | Γενική ή στατιστική διαίρεση μιας ακολουθίας σε τμήματα. |
| Κωδικοποιητής | Νευρωνικό τμήμα που μετατρέπει την είσοδο σε αριθμητικές καταστάσεις. |
| EISE | Το σύστημα εκμάθησης μουσικών θέσεων με ιστορικά τεκμηριωμένες εξηγητικές σχέσεις. |
| CRF | Πιθανοτικό υπόδειγμα που επιλέγει συμβατές δομημένες εξόδους. |
| Ημιμαρκοβιανό μοντέλο | Υπόδειγμα που βαθμολογεί ολόκληρα τμήματα μεταβλητού μήκους. |
| Μερική επισημείωση | Επισημείωση όπου δεν έχουν καθοριστεί όλα τα όρια ή όλες οι ετικέτες. |
| Άγνωστη οικογένεια | Περίπτωση που δεν αποδίδεται με ασφάλεια στο γνωστό λεξιλόγιο. |
| Αποχή | Αποφυγή ανασφαλούς τελικής ταξινόμησης. |
| Προεκπαίδευση | Αρχική εκμάθηση γενικών μουσικών σχέσεων σε ευρύτερο σώμα. |
| B0 | Συμβολική περιγραφή χωρίς νευρωνική εκμάθηση αναπαραστάσεων. |
| B1 | Κοινή μαθημένη αρχιτεκτονική χωρίς πρόσθετη εποπτεία ζευγών. |
| B2 | Εποπτεία με ζεύγη της ίδιας οικογένειας χωρίς ιστορική εξηγητική σχέση. |
| Δ_hist | Σύγκριση EISE και B2 στο ανεξάρτητο εκτελεστικό κριτήριο. |
| ΠΕ0 | Αρχικό στάδιο απογραφής, επισημείωσης και ελέγχου επάρκειας. |
| u₁, u₂, u₃ | Σημειογραφικός χαρακτήρας, ατομικό γεγονός και σύνθετη νευματική μονάδα. |
| N, T, M, L | Μελωδική/σημειογραφική, χρονική, τροπική και κειμενική πληροφορία. |
| R★ | Η αναπαράσταση που επιλέγεται λειτουργικά από τη M1. |
| F1 | Δείκτης που συνδυάζει ακρίβεια και ανάκληση εντοπισμένων ορίων. |
| PPM | Πρόβλεψη από μερική αντιστοίχιση, με μεταβλητό μήκος προηγούμενου συμφραζομένου. |
| Πληροφοριακό περιεχόμενο | Μέγεθος που αυξάνεται όταν η πιθανότητα ενός γεγονότος μειώνεται. |
| I_F | Πληροφοριακό περιεχόμενο της επόμενης οικογένειας. |
| I_event | Πληροφοριακό περιεχόμενο των επιμέρους γεγονότων μιας συνέχειας. |
| M3a | Ανεξάρτητη μουσικολογική επικύρωση οικογενειών και ορίων. |
| M3b | Ακροαματική δοκιμασία κατηγοριοποίησης με τριάδες. |
| M3c | Μελέτη μουσικής προσδοκίας σε επίπεδο οικογένειας και γεγονότος. |
| Α(z) | Προφίλ ιστορικής μεταβλητότητας εσωτερικής περιοχής της θέσης. |
| Γ(z) | Προφίλ μεταβλητότητας σύγχρονων εκτελέσεων της αντίστοιχης περιοχής. |
| Ευθυγράμμιση | Χρονική αντιστοίχιση γραπτών μουσικών γεγονότων και ηχογράφησης. |
| Ω | Το δηλωμένο σύνολο πηγών, κανόνων και υποδειγμάτων αναφοράς για τη M5. |
| D_fam | Απόκλιση στην κατανομή οικογενειών. |
| D_seq | Απόκλιση στις διαδοχές οικογενειών. |
| D_func | Απόκλιση στη λειτουργική τοποθέτηση οικογενειών. |
| D_within | Διαφοροποίηση της πραγμάτωσης μέσα στην ίδια οικογένεια. |
