## 📲 Οδηγίες Εισαγωγής στο Anki (Desktop, Android & iOS)

### Σε Υπολογιστή (Windows / macOS / Linux)
1. Ανοίξτε το Anki.
2. Επιλέξτε **File (Αρχείο) ➡️ Import (Εισαγωγή)**.
3. Επιλέξτε το αρχείο `anki_flashcards.tsv`.
4. Επιβεβαιώστε τις ρυθμίσεις:
   - **Type:** Basic (Βασική)
   - **Deck:** Δημιουργήστε νέο deck με όνομα π.χ. `Byz PhD Makris Prep`
   - **Field separator:** Tab
   - **Field 1:** Front (Εμπρός)
   - **Field 2:** Back (Πίσω)
5. Πατήστε **Import**. Συγχρονίστε με το AnkiWeb για να περάσουν αυτόματα στο κινητό.

### Σε Android (AnkiDroid)
1. Κατεβάστε το αρχείο `anki_flashcards.tsv` στη συσκευή.
2. Στο AnkiDroid, πατήστε το μενού (3 τελείες) ➡️ **Import**.
3. Επιλέξτε το αρχείο `.tsv` και αντιστοιχίστε τα πεδία.

### Σε iOS (AnkiMobile)
- Ο ευκολότερος τρόπος είναι να κάνετε την εισαγωγή στο Anki Desktop και έπειτα απλό **Sync** μέσω AnkiWeb στο iPhone/iPad.
