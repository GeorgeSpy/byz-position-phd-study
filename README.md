### Αρχή ερμηνείας

Η μελωδική ομοιότητα, η οικογενειακή συγγένεια και η ιστορικά τεκμηριωμένη εξηγητική σχέση δεν ταυτίζονται. Τα αριθμητικά αποτελέσματα αναφέρονται πάντοτε στο υλικό, στα κριτήρια αξιολόγησης και στις πηγές που τα υποστηρίζουν.

Το αποθετήριο είναι σημειωματάριο μελέτης της ερευνητικής πρότασης. Δεν αποτελεί κύριο αποθετήριο πειραματικού κώδικα ή πρωτογενών μουσικών δεδομένων.
