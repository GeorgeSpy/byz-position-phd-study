# Η μουσική θέση ως υπολογιστική μονάδα της βυζαντινής μουσικής

**Αναγνωστήριο ερευνητικής πρότασης — Γεώργιος Σπυριδάκης**

[Οδηγός επιστημονικής περιήγησης](NAVIGATION.md) · [Για επιβλέποντες και συνεργάτες](docs/start/review-guide.md) · [Βιβλιογραφία ανά θέμα](docs/bibliography/by-topic.md)

Πώς αναγνωρίζεται μια μουσική θέση όταν η μελωδική της πραγμάτωση μεταβάλλεται; Και τι πληροφορία προσφέρουν οι ιστορικά τεκμηριωμένες παράλληλες εξηγήσεις για τη μάθηση αυτής της ταυτότητας;

Η πρόταση συνδέει τη βυζαντινή μουσικολογία με την ανάκτηση μουσικής πληροφορίας (MIR) και τη μηχανική μάθηση (ML). Μελετά τη θέση ως μονάδα μεταβλητής έκτασης, εξετάζει την πληροφορία της ιστορικής εποπτείας και εφαρμόζει το πλαίσιο στον χαρακτηρισμό πλήρων έργων.

![Μελωδικός τύπος και καταγεγραμμένες παραλλαγές](docs/assets/formula-variation.png)

Το `00001` είναι προσωδιακό πρότυπο πέντε συλλαβών. Τα χρώματα παρουσιάζουν καταλογογραφικές παραλλαγές. [Πώς διαβάζεται το παράδειγμα](docs/examples/index.md).

Η πορεία ανάγνωσης είναι **ταυτότητα θέσης → ιστορική παραλλαγή → χαρακτηρισμός πλήρους έργου**. Κάθε συνοπτική ενότητα οδηγεί στο πλήρες κείμενο και στα αντίστοιχα τεχνικά παραρτήματα.
